A1 · 내부 분석 ①

층별 선형 분류기

각 층의 이미지 토큰에 판별기 하나만 붙여 “이 화면에 red marker가 있나”를 맞힌다. 학습에 쓰지 않은 에피소드로 채점(5겹 교차검증 AUC). 단순한 판별기는 정보를 만들어 내지 못하므로, 맞히면 그 층에 정보가 있다.

A1 · 내부 분석 ②
